# Smoke and Fire Detection

This repository contains the work for the ARTI403 course project.

## Dataset

* **Dataset download:** [Google Drive](https://drive.google.com/file/d/150rNlv_4tzQJDDN9ebP209aNT6X93Ovc/view?usp=sharing). The dataset is hosted externally because of its size.

* **Original dataset source:** [D-Fire GitHub repository](https://github.com/gaia-solutions-on-demand/DFireDataset)

* **Related paper using the dataset:** [An automatic fire detection system based on deep convolutional neural networks for low-power, resource-constrained devices](https://link.springer.com/article/10.1007/s00521-022-07467-z)

Credit for the dataset goes to its original creators. This repository contains our project work using the dataset.
